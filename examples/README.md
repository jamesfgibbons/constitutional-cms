# Synthetic Examples

**Provenance mode: synthetic**

Everything under `examples/` is domain-neutral teaching material created for this public repository. Start with [`hello-site/`](hello-site/) to produce a CLI receipt from synthetic evidence. The examples do
not describe a customer, production deployment, private entity map, or measured outcome. Replace their entities,
thresholds, and ownership labels before using the contract grammar in an implementation.

The manifest and link-target examples demonstrate the public/private adapter boundary. Their origins, route families,
eligibility decisions, and timestamps are fabricated.
